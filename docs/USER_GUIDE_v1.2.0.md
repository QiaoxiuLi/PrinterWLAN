# PrinterWLAN v1.2.0 使用说明

适用系统：Windows Server 2025 x64
适用对象：负责安装和日常管理的普通管理员，以及通过浏览器提交文件的普通用户

PrinterWLAN 把一台 Windows Server 2025 变成局域网网页打印服务器。管理员在服务器上统一选择打印机、创建用户；普通用户不安装客户端，也不选择打印机，只需在浏览器上传 PDF 或 Word 文件并设置当前打印机支持的参数。

> v1.2.0 已完整验证的服务器平台是 Windows Server 2025 x64。Windows 10/11 与实体打印机的更广泛正式适配安排在后续版本。本程序不包含打印机厂商驱动。

## 1. 安装前准备

请准备：

- 一台 Windows Server 2025 x64 服务器，并使用管理员账号操作；
- 已接入受信任局域网，客户端能够访问服务器 TCP 8080 端口；
- 已在 Windows 中正确安装的目标打印机和 x64 驱动；
- 从 GitHub Release 下载的 `PrinterWLAN-Setup-x64.exe` 与 `PrinterWLAN-Setup-x64.exe.sha256`。

PrinterWLAN 安装包已包含 .NET、Visual C++ Runtime、PDF.js、PDFium/SkiaSharp 和 LibreOffice。服务器不需要另装 .NET、Microsoft Office、LibreOffice、Node.js、Python 或 Java。打印机厂商驱动仍需管理员自行安装。

建议先在 Windows 的“打印机和扫描仪”中完成一次测试打印，并确认该打印队列不是只属于某个临时登录会话。PrinterWLAN 服务使用 `LocalSystem` 身份，网络共享打印机也必须允许该服务身份访问。

## 2. 校验并安装

在安装包所在目录打开 PowerShell，计算 SHA-256：

```powershell
Get-FileHash .\PrinterWLAN-Setup-x64.exe -Algorithm SHA256
```

将输出与 `.sha256` 文件中的哈希逐字比较。一致后，右键安装包并选择“以管理员身份运行”。安装程序会自动：

- 配置随包提供的 Microsoft Visual C++ Runtime；
- 安装 `PrinterWLAN` Windows Service；
- 设置为延迟自动启动并依赖 Windows Print Spooler；
- 配置服务异常后的自动恢复；
- 创建 TCP 8080 入站防火墙规则；
- 添加系统 PATH、开始菜单管理入口和管理员登录后的管理控制台任务。

安装不会要求联网下载依赖。完成后，“PrinterWLAN 管理控制台”会保持打开，不会执行一次后自动关闭。

## 3. 设置管理员密码

在管理控制台输入：

```cmd
printerwlan pwd "请换成至少8个字符的密码"
```

密码立即生效。管理员网页登录没有用户名，只输入这里设置的密码。修改密码时再次运行同一命令即可。

不要把真实管理员密码写进批处理、聊天记录或共享文档。密码遗忘时，可在服务器管理控制台中重新设置，不需要重装。

## 4. 检查运行状态

常用命令：

```cmd
printerwlan status
printerwlan doctor
```

`status` 显示版本、服务状态、网站状态、HTTP 端口、可访问的局域网地址和 Windows 可见打印机数量。请把其中类似下面的地址提供给用户：

```text
http://192.168.1.20:8080
```

`doctor` 检查 Windows 版本与架构、PDF.js、LibreOffice、SQLite、PDFium、SkiaSharp、ProgramData 读写、Print Spooler 和打印机可见性。出现“失败”时先不要投入使用；出现“尚未找到打印机”提示时，请先安装或修复打印机驱动。

也可以从开始菜单再次打开“PrinterWLAN 管理控制台”。窗口打开后会自动显示当前状态，并保持在命令提示符，管理员可继续输入上述命令。

## 5. 登录管理后台

在服务器或同一局域网设备的浏览器打开 `http://服务器IP:8080`，点击页面右下角“管理员登录”，输入管理员密码。

PrinterWLAN v1.2.0 使用局域网 HTTP，不会把访问重定向到 HTTPS。不要把 8080 端口直接暴露到公共互联网；如组织必须使用 TLS，请由网络管理员在可信边界配置反向代理。

## 6. 设置所有用户统一使用的打印机

进入“打印机设置”，系统会列出 Windows 当前安装的打印机、状态和 Windows 默认标记。点击目标打印机旁的“设为当前打印机”。

此选择是全局设置：

- 所有普通用户统一使用这台打印机；
- 普通用户看不到打印机名称、ID、列表或选择器；
- 服务或服务器重启后选择仍然保留；
- 管理员切换打印机只影响之后提交的新任务；
- 已选打印机被删除、改名、离线或不可用时，系统不会偷偷切换到其他打印机。

如果尚未配置打印机，普通用户仍能上传和预览文件，但不能提交打印。更换或修复驱动后回到此页面点击“刷新列表”，必要时重新选择。

## 7. 导入用户

进入“用户设置”，准备 UTF-8 CSV 文件：

```csv
用户名
张三
李四
John Smith
```

导入后，每个新用户生成一个 10 位随机密码。管理员可在列表中按需显示、复制密码，或点击“导出用户名密码”保存凭据 CSV。请通过安全渠道分别发送给用户。

重复导入已有用户名会为该用户生成新密码，旧密码立即失效，但用户原来的排序位置保留。建议每次导入或重置后及时导出并妥善保存最新凭据。

## 8. 普通用户打印 PDF 或 Word

普通用户按以下步骤操作：

1. 在手机、平板或电脑浏览器打开管理员提供的局域网地址。
2. 输入用户名和 10 位密码，点击“登录”。
3. 点击“选择文件”或把文件拖到上传区。支持 PDF、DOC、DOCX，单个文件最大 100 MB。
4. 等待预览出现，核对文件名、页数和页面内容。
5. 设置纸张、方向、单双面、页码范围、份数、颜色、纸盒、打印质量、缩放和居中。页面只显示管理员所选打印机实际提供的能力。
6. 点击“提交打印”，等待状态变为“已发送到打印机”。

页码范围可以输入 `all`，也可以输入 `1-3,5,7-9`。每个任务的“选中页数 × 份数”最多为 20；更大的任务请拆成多次提交。每位用户 60 秒内最多创建一个新任务。

“已发送到打印机”表示 Windows 已接受任务，不等于纸张已经完成输出。卡纸、缺纸、缺墨或设备离线仍需现场查看打印机。

## 9. 使用记录与诊断日志

管理后台“使用记录”可筛选访问、登录、上传、预览、打印提交和结果，按日志切片导出 ZIP。“清空日志”必须重新输入管理员密码，只清除使用/打印记录和查询缓存，不会删除用户、网站名称或管理员凭据。

服务器上的主要目录：

| 内容 | 位置 |
|---|---|
| 业务数据库、用户与设置 | `C:\ProgramData\PrinterWLAN\Data` |
| 临时上传、转换与导出 | `C:\ProgramData\PrinterWLAN\Temp` |
| 使用和打印记录 | `C:\ProgramData\PrinterWLAN\Logs` |
| 程序诊断日志 | `C:\ProgramData\PrinterWLAN\Diagnostics` |
| 历史查询缓存 | `C:\ProgramData\PrinterWLAN\Cache` |

上传正文不会写入业务数据库或使用记录。任务完成、失败或取消后会尽快清理；无人继续操作的临时文件通常在约 60 分钟后清理。

## 10. 常见问题

### 页面一直显示“正在准备页面”

v1.2.0 已修复局域网 HTTP 下浏览器不提供 `crypto.randomUUID()` 导致的启动问题。请先强制刷新页面；若仍异常，确认服务器确实安装 v1.2.0，并把浏览器 Console 与 `Diagnostics` 日志交给管理员。

### 当前暂未配置打印机

管理员尚未在“打印机设置”中选择当前打印机。上传和预览仍可使用，但打印提交会被阻止。

### 管理员设置的打印机当前不可用

检查 Windows 打印队列、Print Spooler、连接和驱动，然后在后台刷新。系统不会自动换到另一台打印机。

### 管理控制台闪一下就关闭

v1.2.0 的开始菜单、安装结束入口和 ONLOGON 任务均使用持续控制台。如果仍闪退，请确认打开的是 v1.2.0 开始菜单入口，而不是旧安装目录中的批处理，并重新运行安装程序修复。

### Word 文件无法预览

运行 `printerwlan doctor`，确认内置 LibreOffice 检查通过。也可先把文档另存为 PDF 再上传。受密码保护或损坏的文档不会被转换。

### 网页打不开

在服务器执行 `printerwlan status`，再本机访问 `http://127.0.0.1:8080/health`。确认服务运行、防火墙规则存在、客户端与服务器在可互访网络，且没有其他程序占用 8080。

## 11. 升级与卸载

从 v1.1.0 安装 v1.2.0 时，直接运行新版安装包完成原地升级。安装器会更新现有服务，不先删除再重建；网站名称、管理员密码、用户及密码数据、统一打印机设置、Activity、Diagnostics 和业务数据会保留。

卸载可从 Windows“已安装的应用”或开始菜单执行。卸载会移除程序文件、Windows Service、防火墙规则、ONLOGON 管理任务和 PATH 项，并询问是否保留 `C:\ProgramData\PrinterWLAN`：

- 选择“是”：保留用户、设置和日志，日后重装可继续使用；
- 选择“否”：永久删除全部 PrinterWLAN 数据，此操作无法撤销。

卸载或升级前如需额外保护，请先备份整个 `C:\ProgramData\PrinterWLAN` 目录。

## 12. 安全使用提醒

- 只在受信任 LAN/VPN 中使用，不要把 8080 直接开放到互联网；
- 不要共享管理员密码，普通用户使用各自账号；
- 定期查看登录失败和打印失败记录；
- Windows Server、打印机驱动和固件应按组织策略更新；
- 实体打印机型号、纸盒和双面行为应由管理员现场做一次验收。
